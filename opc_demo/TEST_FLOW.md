# OPC OS Demo 测试流程

> 打开浏览器访问 `http://localhost:8080`，按以下步骤走一遍

---

## Step 1 · 入职引导（30秒）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1.1 | 看到欢迎页，点击 **「🚀 开始搭建我的公司」** | 进入公司信息填写页 |
| 1.2 | 公司名默认"初序健康"，行业选"大健康"，CEO名"Zoey"，点 **「下一步」** | 进入模板选择页 |
| 1.3 | 选中 **「初序健康」** 模板（默认高亮），点 **「下一步」** | 进入 Agent 加载动画 |
| 1.4 | 等待 4 个 Agent 逐个连接（子默→恺撒→明哲→知远） | 进度条走满后自动进入主界面 |

---

## Step 2 · 公司驾驶舱

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 2.1 | 自动进入驾驶舱 | 右上角 Toast 弹出"欢迎回来" |
| 2.2 | 观察 4 个统计卡片 | 数字有**跳动动画**（从 0 滚到目标值） |
| 2.3 | 看营收趋势图 | Chart.js 折线图显示近 7 天营收 vs 成本 |
| 2.4 | 看右侧实时动态 | 8 条活动日志，含时间、Agent 名、操作内容 |
| 2.5 | 往下滚，看 Agent 状态概览 | 4 个 Agent 卡片，状态灯闪烁，进度条显示任务完成率 |

---

## Step 3 · 组织架构

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 3.1 | 点左侧 **「🏢 组织架构」** | 显示树形架构图 |
| 3.2 | 观察层级 | CEO(Zoey) → 4 个部门 → 每个部门 1 个 Agent |
| 3.3 | 鼠标悬浮 Agent 卡片 | 卡片有发光上浮效果 |

---

## Step 4 · 任务中心

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 4.1 | 点左侧 **「📋 任务中心」**（带红色角标 3） | 显示四列看板 |
| 4.2 | 查看四列 | 待办(2) / 进行中(3) / 审核中(1) / 已完成(2) |
| 4.3 | 每张任务卡片 | 有优先级圆点(🔴🟡🟢)、标题、负责人、截止日期 |

---

## Step 5 · Agent 管理

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 5.1 | 点左侧 **「🤖 Agent 管理」** | 显示 4 张大卡片 |
| 5.2 | 每张卡片内容 | 头像、名字、角色、技能标签、Token 用量进度条、平台、最近活跃时间 |

---

## Step 6 · AI 健康管家

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 6.1 | 点左侧 **「💚 AI 健康管家」** | 显示对话界面 + 快速入口 |
| 6.2 | 在对话框输入"你好"，点发送 | 显示打字动画（三个跳动圆点），1秒后 AI 回复体质评估问题 |
| 6.3 | 再输入"B"，点发送 | AI 继续追问睡眠质量 |
| 6.4 | 再输入"C"，点发送 | AI 返回木型体质判断 + 养生方案 + 商城推荐 |
| 6.5 | 点右侧 **「🔍 开始体质测评」** 按钮 | 对话区追加测评开始消息 + Toast 提示 |
| 6.6 | 点 **「🍽️ 今天吃什么」** | Toast 弹出"已生成今日饮食推荐" |

---

## Step 7 · 健康商城

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 7.1 | 点左侧 **「🛒 健康商城」** | 显示 6 个商品卡片 |
| 7.2 | 每张卡片内容 | 大 Emoji 图标、标签、名称、描述、体质推荐标签、价格(划线原价)、销量、佣金 |
| 7.3 | 点顶部 **「🌿 节气推荐」** 筛选按钮 | 只显示带"节气推荐"标签的商品 |
| 7.4 | 点 **「全部」** 恢复 | 全部商品重新显示 |
| 7.5 | 点任意商品的 **「生成推广链接」** | Toast 弹出"已生成CPS推广链接" |

---

## 整体检查项

- [ ] 页面切换有淡入动画，不是硬切
- [ ] 所有卡片 hover 有发光上浮效果
- [ ] 统计数字有从 0 滚动的动画
- [ ] 侧边栏当前页高亮（左边有紫色竖条）
- [ ] Agent 状态灯有呼吸闪烁动画
- [ ] Toast 通知从右侧滑入，3秒后自动消失
