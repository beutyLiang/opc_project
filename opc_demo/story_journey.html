核心问题解答

📢 引流渠道是什么？

并行，但有主次。
主渠道：自媒体短视频/图文（由 AI Agent 明哲负责生产）。
辅助渠道：H5 页面用户测评后裂变分享。
未来渠道：企微朋友圈自动运营。

🤖 AI 客服在哪里？

两个地方，角色不同：
1. H5页面上的AI = 导购员（接待、引导测评、推商品）。
2. 企微里的AI = 私人顾问（日常养生提醒、售后）。

🎯 人群筛选怎么做？

系统自动静默打标签。
根据测评结果（如"木型体质"）、渠道来源、行为轨迹（"已购买"、"沉默7天"），系统自动分类，无需人工。

👥 社群怎么运营？

社群 = 按体质分类的企微群。
例如"木型体质·养肝群"，不同群推送不同内容，实现精准养生服务，杜绝无脑群发。

🛒 精准营销怎么做？

CEO配置规则，AI执行。
给"木型体质"推养肝茶，给"7天未互动"推唤醒内容，给"复购客"推新品。千人千面。

🔄 复购裂变怎么做？

复购：系统根据产品消耗周期自动发补货提醒。
裂变：给老客户专属分享链接，邀请好友双方得券，AI自动追踪来源发奖。

原型中怎么体现？

原型暂时不真实接通企业微信，而是**用 C 端 H5 页面模拟整个用户旅程**：

  1. C 端首页 → AI 气泡弹出引导测评（模拟"AI 客服接待"）
  2. C 端测评页 → 5 题选择 → 出报告（模拟"人群筛选"中的数据采集）
  3. C 端报告页 → 显示企微二维码（模拟"引入私域"，原型中点击后弹 toast）
  4. C 端商城 → 基于体质推荐产品 → 模拟购买（模拟"精准营销"）
  5. C 端分享页 → 生成邀请链接（模拟"复购裂变"）
  6. Boss 端全程实时看到数据变化 → 证明"系统在自动运转"

注：企业微信群聊部分，在 Boss 端"社群管理"页面用模拟对话流展示即可。
