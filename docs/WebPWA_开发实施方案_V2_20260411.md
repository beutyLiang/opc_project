## Proposed Changes

### 前端核心升级

#### [MODIFY] [app.js](file:///d:/projects/opc-project/frontend/app.js)
- **AI 对话 A/B 双路径**：
  - A 路径（主线）：OpenClaw Daemon `/v1/chat/completions`（Spike 已验证通过）
  - B 路径（Fallback）：直接调 Coze Chat API 或 iframe 嵌入扣子 Bot
  - 配置项 `API_MODE = 'openclaw' | 'coze'`，一键切换
- **流式渲染 + 降级**：优先 SSE 打字机效果；若后端不支持流式，降级为伪打字机（逐字渲染完整文本）
- **XSS 防护**：用户输入统一用 `textContent` 替代 `innerHTML`，AI 返回内容用 DOMPurify 过滤
- **数据追踪桩**：localStorage 计数器记录对话次数、"今天吃什么"点击数、CPS 链接点击数
- Loading 状态动画（三点跳动）

#### [MODIFY] [index.html](file:///d:/projects/opc-project/frontend/index.html)
- PWA manifest 引用 + Service Worker 注册
- Apple Touch Icon / 启动图 meta 标签
- **AI 免责声明**（合规红线）
- **简化版体质选择弹窗**：首次访问触发（3 个问题），结果存 localStorage，用于个性化推荐上下文
- **五行测评按钮**：点击跳转扣子 Bot 分享链接（`https://www.coze.cn/s/...`），非死按钮

#### [MODIFY] [styles.css](file:///d:/projects/opc-project/frontend/styles.css)
- Loading 动画样式（三点脉冲）
- 菜谱卡片组件（图片、食材、步骤、CPS 按钮）
- 打字机光标动画
- 体质选择弹窗样式
- safe-area-inset 移动端适配

#### [NEW] [manifest.json](file:///d:/projects/opc-project/frontend/manifest.json)
- PWA 配置：名称"初序"、主题色、图标（192×192 + 512×512）、display: standalone

#### [NEW] [sw.js](file:///d:/projects/opc-project/frontend/sw.js)
- 缓存静态资源（HTML/CSS/JS/字体），离线可访问

#### [NEW] [recipe-api.js](file:///d:/projects/opc-project/frontend/recipe-api.js)
- **不直接暴露 API Key**：所有天行数据请求经后端代理 `/api/recipe`
- 本地缓存（localStorage）减少重复调用
- 降级：API 不可用时展示预置推荐菜谱

#### [NEW] 后端新增 recipe 代理路由（凯撒 FastAPI 侧）
- 在 OpenClaw Daemon 的 FastAPI 中加一个 `/api/recipe` 路由
- Key 存服务端 `.env`，前端零暴露

> [!IMPORTANT]
> **天行数据 API Key**：需要 Zoey 去 tianapi.com 注册获取（免费）。开发阶段先用 Mock，Key 到位后配置到 `.env` 即可切换。
>
> **PWA 图标**：需要生成 192×192、512×512（manifest）和 180×180（Apple Touch Icon）三种尺寸 PNG。

## Verification Plan

### 功能测试
1. 打开 `index.html`，验证暗色主题、玻璃态头部、聊天区域、快捷按钮
2. 首次访问触发体质选择弹窗 → 选择后存入 localStorage → 刷新不再弹出
3. 点击"今天吃什么"→ Loading 动画 → 菜谱卡片（含图片、CPS 红包链接）
4. 点击"五行测评"→ 跳转扣子 Bot 链接（非死按钮）
5. 输入框发送消息 → AI 回复气泡（流式或伪打字机）
6. 点击 CPS 链接 → 正确跳转外卖红包页面

### PWA 与离线测试
7. DevTools → Application → 确认 Manifest 和 Service Worker 注册成功
8. 断开网络 → 刷新页面 → 静态 UI 仍可加载（离线缓存生效）

### 异常与兼容性测试
9. 模拟天行 API 超时/报错 → 降级显示预置菜谱
10. 模拟 OpenClaw Daemon 不可用 → 切换 Coze Fallback 或展示提示
11. Chrome + Safari Mobile 双浏览器验证
12. DevTools 切 iPhone/Android 尺寸验证响应式

### 数据追踪验证
13. F12 → Application → localStorage → 检查对话次数、点击计数器正常累加
