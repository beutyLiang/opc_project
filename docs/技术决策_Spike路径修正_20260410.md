# 技术决策：48h Spike 路径修正 (2026-04-10)

## 背景
凯撒在 48h Spike 过程中反馈：Coze API 与 OpenClaw 要求的 OpenAI 协议接口不兼容（端点、参数、认证机制均不同）。这是导致他产生“Node.js 绕路”念头的技术诱因。

## 方案评估

### 方案 A：凯撒建议的“先 Node.js 后 B” (已驳回)
*   **优点**：出 Demo 快。
*   **缺点**：完全偏离“验证 OpenClaw 原生生态”的核心命题，破坏项目技术叙事，且产生技术债务。

### 方案 B：子默提议的“Python Adapter + OpenClaw” (核心推荐)
*   **原理**：用 Python 编写一个极简的 Adapter（适配层），将 Coze API 的非标返回包装成标准 OpenAI 格式，再提供给 OpenClaw Daemon 调用。
*   **优点**：
    *   100% 遵循 Python 技术栈约束。
    *   完整闭环 OpenClaw 验证路径，符合 OPC 算法赛对“Agent 生态”的技术硬性要求。
    *   代码整洁，符合《统一编码规范》。

## 最终判定
1.  **架构对齐**：凯撒必须立即切换至 **Python Adapter** 路线。
2.  **资源解封**：建议 Zoey 授权发放 **Coze PAT** 与 **Bot ID**，否则 A 轨道将因缺少“大脑”连接而彻底停滞。
3.  **期限不变**：此变动不顺延 4/12 23:59 的止损期限。
