## 任务二：新建 AI 个性化健康商城（H5 页面）

### 目的
评委做完体质测评后，微信里发一个链接，打开就是**只卖适合他的东西**的专属商城。

### 文件位置
在 `frontend/` 目录下新建：`shop.html` + `shop.css` + `shop.js`

### 技术方案
纯静态前端页面，通过 URL 参数 `?element=wood` 来展示不同体质对应的商品。

### URL 参数规则
```
shop.html?element=wood   → 展示"木型·护肝"商品
shop.html?element=fire   → 展示"火型·养心"商品
shop.html?element=earth  → 展示"土型·健脾"商品
shop.html?element=metal  → 展示"金型·润肺"商品
shop.html?element=water  → 展示"水型·补肾"商品
```

## 任务三：优化现有健康报告页面

### 现状
`frontend/report-preview.html` 已经有基础框架，包括：
- 体质概述（免费区）
- 专属饮食方案（付费模糊区）
- 购买 CTA（¥9.9 / ¥29.9）

### 需要优化的地方

#### 3.1 增加雷达图（五行占比可视化）

在报告顶部增加一个 Chart.js 雷达图，直观展示用户的五行占比。

```javascript
// 示例数据（木型体质偏旺的用户）
const radarData = {
    labels: ['木·肝', '火·心', '土·脾', '金·肺', '水·肾'],
    datasets: [{
        label: '你的五行指数',
        data: [85, 45, 60, 50, 40],  // 木型偏高
        backgroundColor: 'rgba(45, 106, 79, 0.2)',
        borderColor: '#2d6a4f',
        pointBackgroundColor: '#2d6a4f'
    }]
};
```

**实现方式**：在 `report-preview.html` 的 `<section class="free-section">` 里，体质概述下方加一个 `<canvas id="radarChart">` ，用 Chart.js 画。

**需要引入 Chart.js CDN**：
```html
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.7/dist/chart.umd.min.js"></script>
```

#### 3.2 增加"饮食红绿灯"板块

在免费区增加一个直观的"宜吃/忌吃"对照表：

```
┌─────────────────────────────────┐
│ 🟢 宜吃              🔴 忌吃    │
├─────────────────────────────────┤
│ 菠菜、枸杞、山楂     辣椒、油炸  │
│ 绿豆、芹菜、菊花     浓茶、烈酒  │
│ 柠檬、醋、梅子       煎烤、羊肉  │
└─────────────────────────────────┘
```

**数据来源**：可以从现有的 `recipe-data.js` 中的 `RECIPE_DATABASE` 提取每个体质对应的食材。

#### 3.3 增加商城入口

在报告底部（购买 CTA 上方）增加一个链接按钮：

```html
<a href="shop.html?element=wood" class="cta-btn shop-link">
    🛒 查看为你推荐的调养好物
</a>
```

让体质报告和商城形成闭环。

#### 3.4 让报告根据 URL 参数动态切换体质

目前报告是写死的"土型体质"。需要改成根据 URL 参数 `?element=wood` 动态切换所有内容。

```javascript
// 从 URL 获取体质
const urlParams = new URLSearchParams(window.location.search);
const element = urlParams.get('element') || 'earth';  // 默认土型
```

然后根据 `element` 值动态填充：标题、描述、雷达图数据、红绿灯数据、食谱方案等。
