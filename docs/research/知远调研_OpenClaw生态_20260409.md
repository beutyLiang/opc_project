# 知远调研：OpenClaw生态 × 初序

> 调研人：知远 | 审核：子默 | 2026-04-09

## 结论先行
腾讯通过 OpenClaw 彻底打通了微信/QQ 的 Agent 入口。"初序"应通过腾讯云 Lighthouse 模版快速部署，利用"ClawBot"形态直接在微信生态内截流用户。

## 1. OpenClaw 最新进展（2026年4月）
- **生态爆发：** 截至 4 月，OpenClaw 1.0 稳定版已获超 150 家组织支持，成为"一人公司 (OPC)"的首选底层。
- **腾讯深度集成：** 腾讯已推出"ClawBot"工具，将 OpenClaw 协议深度嵌入微信及企业微信的消息系统。

## 2. 微信/QQ 里的 Agent 入口形态
Agent 不再以小程序形式隐藏，而是直接转化为**"联系人"**。

- **ClawBot 模式：** 在微信/QQ 中，"初序"表现为一个标准好友位。用户通过自然语言指令（如"帮我整理昨天的体检报告"）直接驱动 Agent 执行跨平台任务。
- **多端联动：** 腾讯 QClaw 平台支持用户通过微信远程操作 PC 端文件或执行自动化流，数据通过本地部署（如私有云）保障隐私。

## 3. "初序"获取用户的机会点
- **极简转化路径：** 用户无需下载 App，扫码添加"初序"为微信好友即可完成激活。这种"无感接入"可大幅降低新用户获取成本。
- **快速部署：** 我们可以通过腾讯云 Lighthouse 的 OpenClaw 应用模版进行 24/7 挂机部署，实现极低成本的运维支撑。
- **B 端渗透：** 利用企业微信的 MCP 能力，我们可以将"初序"快速导入 10 人以下的小型 OPC 团队，满足办公提效刚需。
