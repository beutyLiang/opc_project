# Web PWA 前端开发实施方案

将初序的 Web PWA 从 Mock 骨架升级为可演示的完整 Demo，接入真实 API，达到 OPC 大赛评委可交互的标准。

## 现有基础（凯撒已完成）

| 文件 | 状态 | 内容 |
|------|------|------|
| `frontend/index.html` | ✅ 骨架就绪 | 暗黑主题、聊天容器、快捷按钮（今天吃什么、五行测评）、输入框 |
| `frontend/styles.css` | ✅ 设计系统就绪 | 玻璃态 header/footer、暗色调色板、动画系统、响应式布局 |
| `frontend/app.js` | ⚠️ 纯 Mock | 发送消息和"今天吃什么"都是硬编数据，未接入任何 API |

## Proposed Changes

### 前端核心升级

#### [MODIFY] [app.js](file:///d:/projects/opc-project/frontend/app.js)
- 接入凯撒的 OpenClaw Daemon API（`/v1/chat/completions`），替换 Mock 回复
- 实现流式（SSE）响应渲染，打字机效果逐字显示 AI 回复
- "今天吃什么"按钮触发时，构造带五行体质上下文的 prompt 发送给后端
- 添加 Loading 状态动画（三点跳动）
- XSS 防护：对用户输入做转义

#### [MODIFY] [index.html](file:///d:/projects/opc-project/frontend/index.html)
- 添加 PWA manifest 引用（`<link rel="manifest">`）
- 添加 Service Worker 注册脚本
- 添加 Apple Touch Icon 和启动图 meta 标签
- 补充 AI 免责声明文字（合规红线要求）

#### [MODIFY] [styles.css](file:///d:/projects/opc-project/frontend/styles.css)
- 添加 Loading 动画样式（三点脉冲）
- 添加菜谱卡片组件样式（图片、食材、步骤、CPS 按钮）
- 添加打字机光标动画
- 微调移动端适配（safe-area-inset）

#### [NEW] [manifest.json](file:///d:/projects/opc-project/frontend/manifest.json)
- PWA 配置：名称"初序"、主题色、图标、display: standalone、start_url

#### [NEW] [sw.js](file:///d:/projects/opc-project/frontend/sw.js)
- Service Worker：缓存静态资源，实现离线可访问（评委演示时网络不稳的保险）

---

### 菜谱 API 集成

#### [NEW] [recipe-api.js](file:///d:/projects/opc-project/frontend/recipe-api.js)
- 封装天行数据菜谱 API 调用（关键词搜索、分类查询）

## Verification Plan

### 浏览器测试（主要验证方式）
1. 用浏览器打开 `frontend/index.html`
2. 验证页面渲染：暗色主题、玻璃态头部、聊天区域、快捷按钮可见
3. 点击"今天吃什么"→ 应显示 Loading 动画 → 渲染菜谱卡片（含图片、食材、CPS 红包链接）
4. 在输入框输入文字按回车 → 用户消息气泡出现 → AI 回复气泡出现（Mock 或真实 API）
5. 检查移动端响应式（浏览器 DevTools 切换到 iPhone/Android 尺寸）
6. 检查 PWA：DevTools → Application → Manifest 和 Service Worker 是否正确注册

### 手动验证（请 Zoey 确认）
- 视觉是否达到"评委一眼惊艳"的标准
- 品牌调性是否符合初序定位（不玄学、不鸡汤、结构重于情绪）
