## 四、初审暴露的问题

### 问题 1：叙事混乱，两个人说的不是一回事

| 维度 | Zoey 说的 | 刘总说的 | 冲突 |
|------|----------|---------|------|
| 商城模式 | 自建自营 + 加盟赋能 | CPS分销 + 平台工具 | 叶总被搞混了 |
| 产品定位 | 健康服务 + 私域转化 | OPC OS 通用平台 | 到底做哪个？ |
| 赚钱方式 | 供应链/加盟费 | Token/SaaS工具 | 评委听不懂 |
| 技术路线 | "喂知识库" | "LangChain自研" | 能力边界不清 |

> [!CAUTION]
> **这是最大的问题。** 叶总实际上到最后也没搞清楚你们到底靠什么赚钱。复审必须统一口径，一个人主讲，另一个补充。

### 问题 2：过早暴露远期野心

- 初审就展示了 OPC OS 平台 Demo → 叶总说"可以单独拎出来开一个项目"
- 这说明叶总认为这是**两个项目**，而不是一个
- 复审应该**聚焦初序健康这一个项目**，OPC OS 只作为"技术延伸"一笔带过

### 问题 3：缺乏数据支撑

- 没有用户数据（多少人用过、留存率）
- 没有收入数据（哪怕是测试阶段的）
- Token 消耗说"1000-2000"但单位不清楚（元？次？）
- 服务10万客户成本"大几千到1万"→ 凭什么是10万？

### 问题 4：关键问题回答不够精准

- "为什么做中医不做西医" → Zoey 答了很长但核心论点散（政策/个人经历/市场趋势混在一起）
- "推荐不中立" → 答的是"我们只做三高和肠道"，没有正面回应信任机制
- "赚钱方式" → 绕了一大圈说赋能，没有直接说清楚

## 五、复审优化方向（子默建议）

### 🎯 策略 1：统一叙事，一个故事线

```
我们是"初序健康"——一个用 AI 替代传统健康服务团队的一人公司。
↓
问题：传统私域健康服务需要400人团队，成本极高
↓
方案：AI 健康管家替代人工客服，2个人做400人的活
↓
变现：免费服务建信任 → 精准推荐健康产品 → 商城成交
↓
进展：已上线 AI 客服 + 体质评测 + 微信对接
↓
需要 OPC 的：算力补贴 + 办公场地 + 创业辅导
```

### 🎯 策略 2：准备好叶总一定会追问的问题

| 预判问题 | 建议回答要点 |
|----------|------------|
| 西医为什么做中医？ | ① 6年门诊轮岗含中医科 ② 转型后10年专注中医私域 ③ 团队全部是中医专家 ④ 国家政策方向 |
| 有真实收入吗？ | 必须有！哪怕是一单 CPS 佣金也要展示 |
| 推荐中立性？ | 建立"AI推荐+用户评价+第三方认证"三重机制 |
| 和400人团队的关系？ | 是同一体系的升级版，不是从零开始 |
| OPC OS 和初序健康什么关系？ | 初序是核心业务，OS 是运营初序过程中沉淀的工具方法论 |

### 🎯 策略 3：补数据

- [ ] 现有智能体的使用数据（对话数、用户数、完成率）
- [ ] 至少完成一单 CPS 交易（哪怕自己买一单）
- [ ] Token 成本的精确数据（月/用户/对话）
- [ ] 私域的真实规模数据（粉丝数、社群人数）

### 🎯 策略 4：角色分工

| 谁讲 | 讲什么 |
|------|--------|
| **Zoey 主讲** | 行业痛点 + 医疗资源 + 商业模式 + 变现 |
