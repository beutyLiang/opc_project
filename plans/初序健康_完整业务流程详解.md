# 初序健康 · 完整业务流程详解

> 用一个真实用户"小雨"的故事，从她第一次刷到我们的短视频，到她变成回头客并拉来新用户，完整走一遍飞轮六环节。
> 每一步都说清楚：**用户在做什么** + **系统在做什么** + **CEO 需要做什么**。

---

## 先回答你的核心问题

### Q1：引流渠道是什么？
**并行，但有主次。** 
- **主渠道：自媒体短视频/图文**（小红书、抖音、视频号）— 由 AI Agent 明哲负责生产内容，CEO 审核后发布
- **辅助渠道：初序健康 H5 页面本身** — 用户测完体质后分享给朋友，自带传播属性
- **未来渠道：企业微信朋友圈** — 加了企微的用户能看到 AI 发的朋友圈内容

### Q2：AI 客服是在 H5 页面还是企业微信？
**两个地方都有，但角色不同，有先后顺序：**
1. **H5 页面上的 AI 客服** = 导购员，负责"接待 + 引导测评 + 推荐产品"（用户还没加你微信之前）
2. **企业微信上的 AI 客服** = 私人顾问，负责"日常养生提醒 + 精准推送 + 售后"（用户加了微信之后）

用户先在 H5 上被接待 → 测评完后引导加企微 → 进入私域长期运营。

### Q3：人群筛选怎么做？
**系统根据用户行为自动打标签，不需要人工操作。** 标签来源：
- 体质测评结果 → 自动标"木型体质"
- 来源渠道 → 自动标"小红书来源"
- 行为轨迹 → 自动标"已测评"、"已购买"、"高意向"、"沉默7天"

### Q4：社群是什么？和企业微信群有区别吗？
**社群 = 企业微信群，没有区别。** 但我们按体质类型分群：
- "🌿 木型体质·养肝群" — 给测出木型体质的用户
- "🔥 阳虚体质·温阳群" — 给测出阳虚体质的用户
- "⭐ VIP 复购群" — 给已购买过的高价值用户

分群的目的是**精准推送**——不同体质推不同产品和内容，而不是一锅端群发。

### Q5：精准营销怎么做？
**CEO 在后台配置规则，AI 自动执行。** 例如：
- 给"木型体质"标签的用户 → 推养肝茶
- 给"7天未互动"标签的用户 → 推一条节气养生提醒唤醒她
- 给"已购买1次"的用户 → 推同体质的第二款产品

### Q6：复购裂变怎么做？
**两个机制：**
- **复购**：根据产品消耗周期（比如茶叶30天喝完），到期前自动提醒补货
- **裂变**：给老用户一个专属分享链接"邀请好友测体质，双方各得¥5优惠券"，新用户通过这个链接进来会被标记为"裂变来源"

```

│                                                     │

│ 「谷雨时节肝火旺？3个信号说明你该养肝了」                │
│ 视频下方有一行字："点击链接，免费测你的五行体质 →"        │

└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ 系统视角（OPC OS Boss 端）                            │
│                                                     │
│ 这条短视频的脚本，是 CEO Zoey 在任务中心派给               │
```

这一步**没有用户可见的操作**，完全在后台静默发生。

## 六环节对应的系统模块总结

| 飞轮环节 | 用户接触的产品 | Boss 端对应模块 | 核心 Agent |
|---------|--------------|---------------|-----------|
| 流量获取 | 小红书/抖音上的内容 | 任务中心（派发写内容的任务） | 明哲 |
| AI 客服 | C 端 H5 页面 + 企微私聊 | 用户运营（看对话流和转化率） | 知远 |
| 人群筛选 | 用户无感知 | 用户运营（看标签和画像分布） | 知远 |
| 社群运营 | 企业微信群 | 社群管理（看群活跃度） | 子默 |
| 精准营销 | 企微私信收到的推荐 | 营销中心（配置推送规则） | 明哲+知远 |
| 复购裂变 | C 端分享页 + 商城 | 营销中心（看裂变数据） | 子默+知远 |

## 原型中怎么体现？

原型不需要真的接通企业微信，而是**用 C 端 H5 页面模拟整个用户旅程**：

1. C 端首页 → AI 气泡弹出引导测评（模拟"AI 客服接待"）
2. C 端测评页 → 5 题选择 → 出报告（模拟"人群筛选"中的数据采集）
3. C 端报告页 → 显示企微二维码（模拟"引入私域"，原型中点击后弹 toast）
4. C 端商城 → 基于体质推荐产品 → 模拟购买（模拟"精准营销"）
5. C 端分享页 → 生成邀请链接（模拟"复购裂变"）
6. Boss 端全程实时看到数据变化 → 证明"系统在自动运转"

企业微信群聊部分，在 Boss 端"社群管理"页面用**模拟对话流**展示即可。
