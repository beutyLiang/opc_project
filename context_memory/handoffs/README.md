# AI 团队交接协议 v2.0（OPC比赛专用）

> 频道：`opc-lobster`

## 通信模板

### 子默派任务
```
## [opc-lobster] 任务
- 做：一句话
- 文件：路径
- 完成后：交完成报告
```

### 凯撒交结果
```
## [opc-lobster] 完成
- 做了：一句话
- 改了：文件路径列表
- 风险：有/无
```

### 需要决策
```
## [opc-lobster] 需决策
- 问题：一句话
- 选项：A / B
- 建议：判断
```

## 铁律
- 所有消息不超过5行
- 不贴文件内容，只发路径
- 执行类自己干，决策类才找子默
